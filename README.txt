VEHICLEVERSE — MODIFIED PROJECT

FEATURES
1. Explore Vehicles on home page opens categories.html.
2. Categories open their matching category pages.
3. Vehicle cards open individual vehicle details pages.
4. Enquire Now opens the enquiry form with the selected vehicle pre-filled.
5. JavaScript validates the enquiry form and saves records to browser localStorage.
6. Saved Enquiries page shows stored records and lets you delete one or clear all.
7. Responsive HTML/CSS layout, search filters, details/summary sections, and image alt text.

HOW TO RUN
1. Extract this ZIP into a folder.
2. Open index.html in Chrome or Microsoft Edge.
3. Keep internet available for remote vehicle images and Google Fonts.
4. Submit an enquiry and open enquiries.html to see saved details.

IMPORTANT STORAGE LIMITATION
localStorage saves records only in the same browser profile on the same device and for this website origin. Opening the project separately in Chrome and Edge may produce separate records. Clearing browser data can delete records. For a real publicly available website or shared database, deploy it to web hosting and connect a secure backend/database. This front-end-only project does not send orders to a real seller.

SEARCH ENGINE
Opening index.html locally does not make it appear in Google search. To make it searchable online, publish it using a web host and submit the live site to a search engine.

Vehicle names, specifications and prices are illustrative demonstration data.
